This folder contains models for program to work. You should populate it with ggml-(model).bin files and put this folder wherever on your computer. By default, the app will set the path to a model, as if the folder is located near executable file. I might put a script to get all models, but for now you can use GGML's own downloader instead at this [link](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md).
